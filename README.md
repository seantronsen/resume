# Resume

The LaTeX source files contained within this repository may be used to compile a
PDF of my resume. Pre-compiled PDFs can also be found under
[releases](https://github.com/seantronsen/resume/releases).

> [!important]
>
> Although the content of the resume is my own, the document format is derived
> from the template available from this repository:
> [repository](https://github.com/TimmyChan/data-science-tech-resume-template)
